# Memory Management - Laboratory 4

A C++ simulator for studying memory virtualization techniques using real-world memory access traces.

## Assignment

This laboratory consists of five parts:

- **Part I:** Single-level page table
- **Part II:** Two-level page table
- **Part III:** TLB integration
- **Part IV:** Limited physical memory and page replacement
- **Part V:** Simulator performance optimization
